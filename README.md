## 🖥️ Projecten & Labs

### ☁️ Cloud Engineering & Infrastructure (Azure & AWS)
*Praktijkervaring met publieke cloudproviders, netwerkisolatie, Identity & Access Management en Infrastructure as Code.*

- ☁️ **[Azure Cloud Security Lab](https://github.com/tyresetalia/azure-cloud-lab)**  
  Beveiligde Azure-baseline uitgerold via CLI & Portal: Virtual Network (VNet), NSG met strikte IP-whitelisting op beheerpoorten, RBAC (least privilege) en Log Analytics met KQL-queries voor brute-force detectie.

- ☁️ **[Azure Hub-and-Spoke Netwerk](https://github.com/tyresetalia/azure-hub-spoke-lab)**  
  Enterprise multi-VNet netwerkarchitectuur: centrale beheer-hub gekoppeld aan gescheiden productie- en dev-spokes via VNet Peering, met zero-public exposure en strikte netwerkinsulatie.

- ☁️ **[AWS Cloud Security Lab](https://github.com/tyresetalia/aws-cloud-lab)**  
  Beveiligde AWS-omgeving opgezet from scratch: custom VPC, EC2 Linux-workload, restrictieve Security Groups, IAM-toegangsbeheer (least privilege) en CloudWatch audit-monitoring.

- ☁️ **[AWS High Availability Web Lab](https://github.com/tyresetalia/aws-high-availability-web-lab)**  
  Fouttolerante webinfrastructuur: multi-zone architectuur met Application Load Balancer (ALB), Auto Scaling Groups en Health Probes voor 99.9% uptime.

- ☁️ **[AWS Terraform Infrastructure Lab](https://github.com/tyresetalia/aws-terraform-infrastructure-lab)**  
  Infrastructure as Code (IaC): geautomatiseerd uitrollen en beheren van schaalbare cloudresources met herbruikbare Terraform-modules.

- ☁️ **[AWS Cloud Migration Lab](https://github.com/tyresetalia/aws-cloud-migration-lab)**  
  Migratiestrategie en lift-and-shift transitie van on-premises workloads naar AWS cloud-diensten.
